# Games Banner — Polished Arcade

A responsive React/Vite arcade UI with two fully playable mini-games.

## Included
- Premium responsive arcade dashboard using the supplied game artwork.
- Auto-scrolling game carousel with pause-on-hover/touch and navigation dots.
- Persistent Game Coins, Tokens and redemption history via localStorage.
- **Tap Master:** 30-second target tapping, score, combo, best score, revive and rewards.
- **Memory Match:** timed matching game, move counter, pair tracking, shuffle/revive and rewards.
- Animated game overlays and responsive mobile layouts using Framer Motion.
- Protected handling for non-playable/coming-soon games.

## Run
```bash
npm install
npm run dev
```

## Production build

npm run build
